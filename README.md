Arah revisi proyek
Fokus utama proyek adalah website branding dan informasi Yayasan Griya Kemandirian Masyarakat (GKM), bukan sistem pengelolaan data penerima manfaat.
Ketentuan:
Topik dan jenis aplikasi berfokus pada website branding dan informasi GKM.
Website berfokus pada profil yayasan, sejarah, visi dan misi, program, publikasi kegiatan, laporan terverifikasi, serta informasi donasi dan kolaborasi sesuai ketentuan yang berlaku.
Pendataan penerima manfaat menggunakan Google Forms yang terhubung dengan Google Sheets, bukan modul khusus dalam website.
Jenis data atau kolom formulir masih menunggu informasi lebih lanjut dari GKM. Jangan mengarang isinya.
Warna visual website masih menunggu konfirmasi GKM. Jangan menetapkan warna final.
